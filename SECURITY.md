# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x (Workstation MVP) | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in DevCompass, please report it responsibly by contacting the maintainer directly or opening a confidential security advisory.

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within 48 hours and provide a fix timeline.
